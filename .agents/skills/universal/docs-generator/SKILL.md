# Docs Generator Skill

## Cuándo usar
Para documentar arquitectura, mantener el `README.md`, generar especificaciones de API o diseñar diagramas.

## Reglas
1. Mantener formato Markdown semántico y limpio.
2. Al diseñar flujos de arquitectura, utilizar diagramas Mermaid legibles.
3. Para APIs, estructurar basándose en estándares de la industria (ej. OpenAPI 3.0 / Swagger).
4. Asegurar que los comentarios en el código expliquen el *por qué*, no solo el *qué*.
